## 🤝 How to Contribute

We welcome all contributions! If you've discovered new places or want to update existing information:

1. Fork this repository
2. Create your feature branch (`git checkout -b feature/AmazingPlace`)
3. Commit your changes (`git commit -m 'Add some AmazingPlace'`)
4. Push to the branch (`git push origin feature/AmazingPlace`)
5. Open a Pull Request

### Contribution Format Example
```markdown
### Category Name
- **Place Name** - Detailed Address | Key Features | Price Range
  - Detailed description including personal experience, recommended items, best time to visit, etc.
  - 📍 Google Maps Link
  - 🕒 Business Hours
  - 💰 Average Cost
  - ⭐ Personal Rating
```
